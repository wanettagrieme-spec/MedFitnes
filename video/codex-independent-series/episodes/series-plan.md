# Самостоятельная серия Codex — десять выпусков
Дата: 12.10.2026. Новая серия по прямому поручению пользователя; тексты не заимствованы из проекта Claude.

1. **Реабилитация: вернуть свою жизнь.** История привычных действий: чашка, лестница, участие пациента в плане. Новый сценарий и озвучка готовы; оригинальная анимация на проверке.
2. **Кому нужна медицинская реабилитация.** Ограничения после заболевания, решение специалиста, три профиля отделений по нарушенным функциям.
3. **Как устроен маршрут пациента.** ШРМ и переходы между этапами, документы, индивидуальный маршрут.
4. **Первый этап: ранняя реабилитация.** Реанимация и профильное отделение, нагрузка по состоянию; вертикализатор, прикроватный велоэргометр и магнитотерапия по решению специалиста.
5. **Второй этап: работа над самостоятельностью.** Только индивидуальные занятия, три заседания МДРК, реабилитационный эпикриз.
6. **Третий этап: занятия рядом с домом.** Амбулаторное отделение, дневной стационар, помощь на дому при соответствующих условиях.
7. **Ваш индивидуальный план.** Реабилитационный диагноз, цель, индивидуальный план медицинской реабилитации, оценка изменений.
8. **Кто входит в команду.** Роли врача ФРМ, инструктора ЛФК, эрготерапевта, клинического психолога, клинического логопеда, медицинской сестры по медицинской реабилитации.
9. **Как близкие могут помочь.** Поддержка самостоятельности, обучение безопасной помощи у специалистов, участие в постановке целей.
10. **Как замечать прогресс и продолжать безопасно.** Личная отправная точка, обратная связь команде, индивидуальная нагрузка, уточнение рекомендаций при выписке.

Это план серии, а не десять готовых видео. Новые сценарии остаются проектами для медицинской проверки пользователем.
