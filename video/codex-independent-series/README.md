# Самостоятельная серия Codex: медицинская реабилитация
Отдельный проект, начат 12.10.2026 по прямому поручению пользователя.
Новые сценарии, новая запись SpeechKit, новая синтезированная музыка, оригинальная процедурная анимация. Не импортирует сценарии, звуковые дорожки, фотографии, видеоклипы, композиции и субтитры проекта Claude.
Программные библиотеки Remotion/React/Three.js — движок, не материалы прежних роликов. Ключ SpeechKit читается только из существующего защищённого файла настроек; в проект и git не копируется.
