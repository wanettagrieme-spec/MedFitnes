# Инструменты серии 2
- `tts3.py` — озвучка Yandex SpeechKit **v3**: ermil, role=good, speed=0.95, LUFS, словари ударений/произношения серии 1 (как `rehab-series/studio`). Ключ не хранится в репозитории.
- `revoice.py <папка>` — озвучка по абзацам p1..pN, тайминги сцен, `voice_full.wav/mp3`.
- `music.py <сек> <out.wav>` — тихий музыкальный фон (синтез, прав третьих лиц нет).
- `build3.py v|h` — монтаж 9:16 / 16:9: видео Kling (растяжение ≤1,25×) и статичные кадры с наездом ≤5 % от верха, плашки, подписи ролей, субтитры по таймингам Descript, музыка с приглушением на голосе (MUSIC=bed.wav), −14…−16 LUFS.
Правила (15.10.2026): голос и темп как в серии 1; музыка обязательна; ничего не ускорять и не урезать ради хронометража.
