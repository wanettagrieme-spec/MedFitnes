# Завершение сессии (medfit-vault + NotebookLM)

Главная память — medfit-vault (GitHub wanettagrieme-spec/medfit-vault).
NotebookLM — только зеркало для вопросов, подкастов и отчётов по истории работы.
Если они расходятся, прав medfit-vault.

## Шаг 1. Итог сессии

Просмотреть весь разговор и выделить:
- что сделано (создано, исправлено, настроено);
- принятые решения и почему;
- неочевидные находки;
- открытые вопросы на следующий раз;
- новые пожелания пользователя к работе;
- затронутые проекты, файлы, сервисы.

Даты — только абсолютные (ГГГГ-ММ-ДД).

## Шаг 2. Запись в medfit-vault (обязательно, по CLAUDE.md хранилища)

Действовать строго по правилам CLAUDE.md репозитория medfit-vault:
- обновить страницу каждого затронутого проекта;
- запись в Журнал;
- запись в log.md;
- при новых страницах — index.md;
- закоммитить и запушить.

## Шаг 3. finish.py

Запустить `_система/finish.py`. Сессия считается закрытой только после «ГОТОВО».
Если не «ГОТОВО» — исправить замечания и запустить снова. Пока нет «ГОТОВО», шаг 4 не делать.

## Шаг 4. Зеркало в NotebookLM

ID блокнота взять из `_система/notebooklm.md` в medfit-vault.
Если файла нет или блокнот удалён: `notebooklm list --json`, найти
«Медфит — Вторая память», иначе создать `notebooklm create "Медфит — Вторая память" --json`
и записать ID в `_система/notebooklm.md` (только ID и название).

Итог сессии сохранить во временный файл и добавить источником:

```bash
F=$(mktemp -t "сессия-$(date +%F)-XXXX").md   # итог в формате ниже
notebooklm source add "$F" --notebook <ID> --title "Сессия $(date +%F) — <тема>"
rm -f "$F"
```
Если `notebooklm` не найден — `~/.notebooklm-venv/bin/notebooklm`.
Если ошибка входа — сказать пользователю, что нужен `notebooklm login`, и не считать
это провалом сессии: в medfit-vault всё уже сохранено.

Формат итога:

```markdown
# Сессия ГГГГ-ММ-ДД — <тема>
## Что сделали
## Решения
## Находки
## Открытые вопросы
## Проекты и файлы
```

## Шаг 5. Подтверждение

Коротко, по-русски: что записано в medfit-vault, ответ finish.py, добавлен ли итог
в NotebookLM, открытые вопросы на следующий раз. Итог целиком не пересказывать.

## Запрещено

- Записывать куки, токены, пароли, storage_state.json в любые файлы.
- Вставлять в NotebookLM медицинские данные конкретных пациентов.
- Удалять источники или блокноты без прямого подтверждения пользователя.
