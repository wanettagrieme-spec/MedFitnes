# Медицинские исследования

Цель — ответ, на который врач может опереться: каждый факт с проверенным источником, сила доказательств видна, противоречия не спрятаны.

## Порядок источников
1. **Клинические рекомендации Минздрава РФ** — https://cr.minzdrav.gov.ru (рубрикатор). Указывай ID и год редакции, УУР/УДД.
2. **ВОЗ, МКФ** — https://www.who.int ; категории МКФ — кодами (b, s, d, e).
3. **Cochrane** — https://www.cochranelibrary.com
4. **PubMed** — https://pubmed.ncbi.nlm.nih.gov : сначала систематические обзоры и метаанализы, потом РКИ, потом остальное. Предпочтительно последние 5–7 лет; старее — помечай.
5. Прочее (учебники, сайты) — только с пометкой «вторичный источник».

## Проверка — обязательна для каждого источника
- **PMID** — открой запись и сверь название, авторов, год, журнал:
  `curl -s "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi?db=pubmed&id=PMID&retmode=json"`
  Не открылось или не совпало — источник не используешь.
- **DOI** — `https://doi.org/DOI` должен открыться.
- **Цитата** — только дословно из текста, который ты открыл (абстракт или полный текст), с указанием: абстракт / раздел / страница. Нет доступа к полному тексту — пиши «по абстракту».
- **Клинические рекомендации** — ID, год, номер тезиса или страницы. Не открылось — честно: «текст КР не открылся (ошибка …)», а не пересказ по памяти.

## Как писать вывод
- Различай три вида утверждений и помечай их: **рекомендация** (КР, УУР/УДД) · **данные исследования** (тип, n, год) · **вывод/экстраполяция** (твоё обобщение — помечено словом «вывод»).
- Противоречия между источниками — отдельным пунктом, обе стороны со ссылками.
- Не назначай лечение и дозировки от своего имени: «КР рекомендуют …», «в РКИ использовали …».
- Данные пациентов — только обезличенно (инициалы, возраст, диагноз); во внешние сервисы их не отправлять.

## Формат отчёта
```
# Тема — дата
Кратко (3–5 строк): главный ответ.
## Что говорят рекомендации
## Что говорят исследования
## Противоречия и пробелы
## Источники (проверены)
1. Автор, год. Название. Журнал. PMID … / DOI … — проверено: esummary ✓ / doi.org ✓
## Что не получилось
(источник не открылся, нет полного текста и т. п.)
```
Сохраняй отчёт файлом `research/ГГГГ-ММ-ДД-тема.md` и присылай владелице сам файл в Telegram плюс краткую выжимку сообщением.

## Чего не делать
- Не приводить PMID, DOI, цитаты и цифры, которые ты не открыл сам.
- Не сглаживать противоречия и не выдавать вывод за данные исследования.
- Не писать «готово», пока в разделе «Источники» у каждого источника нет отметки проверки.
