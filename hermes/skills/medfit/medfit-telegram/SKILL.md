# Канал @MedFitnes (t.me/MedFitnes)

Подробное состояние — страница базы «Telegram-канал МедФитнес» (`Вики/Проекты/Telegram-канал МедФитнес.md` в medfit-vault). Читай её первой.

## Как устроена публикация

- Посты публикует GitHub Actions в репозитории wanettagrieme-spec/MedFitnes, раз в день: самый ранний пост со статусом `pending`, у которого дата наступила. Не больше одного за запуск.
- Расписание — `telegram/schedule/posts.json` (id, date, rubric, title, body, photo_file, status). Карточки — `telegram/images/post-NN.jpg`.
- Время выхода фактически днём (15–17 МСК) из-за задержек GitHub — владелица решила оставить так.
- Локальная копия: `~/GitHub/MedFitnes` (перед чтением — `git pull`).

## Что ты делаешь сам

- Статус: сколько постов вышло, какие ближайшие, хватает ли запаса. Правило владелицы — запас готовых постов **минимум на 2 недели вперёд**; если меньше — предупреди.
- Проверка запусков: `gh run list -R wanettagrieme-spec/MedFitnes -L 10`.
- Идеи и черновики постов — в стиле канала (ниже).

## Что только с согласия владелицы

Публикация, правка `posts.json`, отправка в канал, удаление — только после её явного «да». Большую работу (план месяца, карточки, подкасты) предложи отдать Claude Code готовым заданием.

## Стиль постов

- Девиз «Умный фитнес». Пропорция: 2 методических/тренировочных поста на 1 бизнес-пост.
- Заголовок-образ + 3–5 пунктов + вывод + вопрос аудитории в конце. 550–700 знаков текста.
- Идеи — из архива журналов Fitness Report 2004–2010 (Google Диск «_МедФитнес ЖУРНАЛЫ», каталог «Fitness Report 2004-2010 — референс-каталог и рубрикатор»), пересказ своими словами, старые цифры сверять с актуальными данными.
- Без медицинских назначений; при заболеваниях — «согласуйте с врачом».
- Подкасты и видеообзоры делаются в NotebookLM (навык `medfit-notebooklm`): подкаст раз в неделю по субботам, видео раз в две недели.
- Визуал карточек: инфографика, фото человека, нейтральный баланс белого, без фиолетово-розовой гаммы, скандинавский типаж; перед платной генерацией фото — словесное описание сцены на согласование.
