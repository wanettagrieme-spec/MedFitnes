## Как записать своё действие (обязательно после каждого действия по проектам)

1. В конец `log.md` (только дописать, файл большой — не перезаписывай):

```markdown

## [ГГГГ-ММ-ДД] (Hermes) сессия — <тема>
- <что сделано / что найдено>
```

2. В конец `Журнал/ГГГГ-ММ-ДД.md` строку: `- (Hermes) <что сделано>`. Если файла за сегодня нет — создай:

```markdown
---
тип: журнал
создано: ГГГГ-ММ-ДД
обновлено: ГГГГ-ММ-ДД
tags:
  - журнал
---

# ГГГГ-ММ-ДД

> [!abstract] Кратко
> <одна фраза о дне>

- (Hermes) <что сделано>
```

Дописывай через `patch`/append, а не `write_file` целиком. Удалять или сокращать строки в `log.md` и Журнале нельзя.

## Как сохранить новое знание

Новым файлом в папку `Входящие/`:
`Входящие/ГГГГ-ММ-ДД Hermes — <короткая тема>.md`

```markdown
---
тип: входящее
создано: ГГГГ-ММ-ДД
автор: Hermes
---
# <тема>
- Что: <факт / решение / идея — словами владелицы, если это её решение>
- Откуда: <голосовой разговор / Telegram / письмо …>
- Касается: [[<страница проекта>]]
```

Не меняй страницы `Вики/`, `index.md`, `CLAUDE.md`, `_система/`. Не делай git commit/push — синхронизацию делает Obsidian Git.
