4. Не сканируй папки целиком: index → страница. Большие страницы читай по заголовкам.

Не исправляй сам. Скажи владелице и запиши заметку во «Входящие».

## Как сохранить новое

Только в папку `Входящие/`, новым файлом:
`Входящие/ГГГГ-ММ-ДД Hermes — <короткая тема>.md`

```markdown
---
тип: входящее
создано: ГГГГ-ММ-ДД
автор: Hermes
---
# <тема>
- Что: <факт / решение / идея — словами владелицы, если это её решение>
- Откуда: <голосовой разговор / Telegram / письмо …>
- Касается: [[<страница проекта>]]
```

Не меняй существующие файлы, не трогай `log.md`, `index.md`, `Журнал/`, `CLAUDE.md`, `_система/`. Не делай git commit/push — синхронизацию делает Obsidian Git.
