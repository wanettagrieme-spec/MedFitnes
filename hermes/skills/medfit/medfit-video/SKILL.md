# Простой монтаж видео

Перед работой прочитай в базе medfit-vault: «Правила кадрирования», «Реалистичная обстановка в кадре», а для роликов серии — «Вторая серия роликов — экспертные Reels о реабилитации» (раздел «Как работаем»).

## Что делаешь сам (ffmpeg на Mac)
- Склейка фрагментов, обрезка начала/конца, замена или наложение звука.
- Вертикаль 9:16 ↔ горизонталь 16:9. Из горизонтального кадра вертикаль режется **снизу, а не по центру** — чтобы не срезать головы; медленный наезд — не больше 5 %, с привязкой к верху.
- Голос + музыка: музыка тихо под голосом и приглушается на речи (sidechain); итоговая громкость −16 LUFS (`loudnorm=I=-16`).
- Субтитры и плашки: небольшие, сверху, на стороне без голов; **никогда не закрывают лица**.
- Сжатие под Telegram: файл до 50 МБ; H.264, `-preset slow -crf 20` (качество важнее скорости), AAC 160k; если не влезает — не ухудшать картинку сразу, а сказать владелице.
- Обложка: кадр без закрытых глаз и смаза, с запасом над головой.

Если ffmpeg не найден (`command -v ffmpeg`) — не ставь программы сам: напиши владелице и предложи задание для Claude Code.

## Запреты (правила владелицы)
- **Не ускорять речь и не резать смысл ради хронометража.** Не помещается — сказать, а не подгонять.
- **Не вставлять надпись «Видеоряд создан с помощью ИИ»** и подобные.
- Голос и темп роликов — как в серии 1 (SpeechKit, Ермил, без ускорения).
- Обстановка в кадре — реалистичная, по этапу реабилитации; без элитных палат и домов.

## Проверка перед «готово»
1. `ffprobe`: длительность, разрешение, звук есть, громкость.
2. Вытащи 6–10 кадров (начало, середина, места склеек, титры) и **посмотри их**: головы целиком, запас сверху, титры не на лицах, нет чёрных кадров.
3. Сохрани в три места (навык medfit-save), запиши в log «(Hermes)».

## Когда передать Claude Code
Новый ролик серии (сценарий, генерация кадров Higgsfield, озвучка SpeechKit, монтаж Descript/Final Cut) — это не простой монтаж. Сформулируй задание одним сообщением для Claude Code и положи его в «Входящие» заметкой.
