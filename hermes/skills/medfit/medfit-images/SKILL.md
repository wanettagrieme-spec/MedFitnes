# Изображения

1. **Сначала словесное описание сцены** — и согласование с владелицей перед любой платной генерацией (её требование: не тратить кредиты на неподходящие и повторяющиеся сюжеты).
2. **Обстановка — по этапу реабилитации** (страница базы «Реалистичная обстановка в кадре»): реанимация / обычная палата на 2–4 койки / больничный зал ЛФК / небольшой кабинет специалиста / квартира среднего уровня / обычный фитнес-клуб. В промпте: «ordinary, modest, realistic, not luxury; no panoramic windows, no designer interior, no single bed in a huge room».
3. **Кадрирование** (страница «Правила кадрирования»): в промпте «heads and faces fully in frame, clear headroom above every head»; после генерации проверь — верх головы не ближе ~3 % высоты к краю; иначе перегенерировать или дорисовать сверху.
4. **Цвет:** нейтральный баланс белого, без цветового фильтра, **без фиолетово-розовой гаммы**. Для канала @MedFitnes — скандинавский типаж внешности.
5. Без надписей и логотипов на фото, без «создано ИИ».
6. **Посмотри результат сам** перед отправкой: лица, руки, лишние пальцы, текст-мусор.
7. Сохрани в три места (medfit-save) и запиши, сколько потрачено кредитов.
