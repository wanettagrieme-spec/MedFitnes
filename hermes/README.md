# Hermes — настройки агента (копия)

Рабочие файлы живут на MacBook в `~/.hermes/`. Здесь — копия для истории и восстановления.

| Файл здесь | Где работает на Mac |
|---|---|
| `SOUL.md` | `~/.hermes/SOUL.md` — характер и правила |
| `MEMORY.md` | `~/.hermes/memories/MEMORY.md` — память |
| `skills/medfit/…` | `~/.hermes/skills/medfit/…` — навыки владелицы |

`config.yaml` сюда не кладём: в нём служебные настройки подключений. Резервные копии прежних файлов — `~/.hermes/backups/claude-2026-11-02/`.
Описание и история — страница «Подключения — Hermes» в medfit-vault.
