Каталог: $ARGUMENTS

Метод проверен на магните, СВЧ, УЗ, УВТ, электротерапии. Подробности и ловушки каждого издания — в базе: «Оцифровка энциклопедий BTL» и «ICF SINGAPORE — движок физиотерапии» (раздел «Энциклопедии BTL»). Прочитай их до начала.

1. **Источник.** Найди PDF на Google Диске (если по названию не находится — поиск по тексту: `fullText contains 'код программы'`). Большой файл (больше ~7 МБ) через Диск рвётся — попроси zip в чат. Не путать похожие издания (УВТ X-WAVE — эстетика, не терапия).
2. **Чтение.** `pypdf.extract_text()` постранично → разбор регулярками → массив. Якорь записи — строка «Программа X-NNNN», а не заголовок. Колонтитул снимать до поиска заголовка. Внутренний номер «(NNNN)» — последнее вхождение (запись переходит на следующую страницу).
3. **Глифы.** «Пр oгpa мм a» и «5 cм²» набраны вперемешку латиницей. Нормализовать только служебное слово «Программа»; значения полей брать из оригинального текста (иначе портится латынь: m.quadriceps).
4. **Разорванные слова** («н е рекомендуется») — склейка по словарю, собранному из самих энциклопедий; однобуквенные предлоги не трогать.
5. **Сверка.** Число записей, затем поле в поле. Классы дефектов, которые уже встречались: съехавшие границы полей, обрезанные значения, затёкший колонтитул, сдвиг на соседнюю нозологию, потерянные примечания и предупреждения.
6. **Не править молча.** Сначала таблица расхождений владелице: запись, поле, в файле, в источнике (страница). Противоречие внутри самого источника — отдельным списком, решение за ней. Правка — только после её сигнала, через `/pravka`.
7. После правки: страница и внутренний номер источника у каждой сверенной записи (основа цепочки «почему»), `tests/expected.json` — если изменилось число записей, `/proverka`, запись в базе (карточка источника — статус разбора; страница проекта — «было → стало»).
