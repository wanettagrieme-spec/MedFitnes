1. Убедись, что `/proverka` пройдена на текущем файле (есть свежий `tests/out/.last_pass`) и, если трогали печать, `/pechat`.
2. Номер: следующий после `APP_VERSION` в файле (15 → 16). Поменяй `APP_VERSION` точечным Edit. `RULES_VERSION` — дата, только если менялась клиническая логика движка. `DATA_SCHEMA` — только если менялся формат карты (и тогда проверь, что старые карты открываются). Ключ хранилища `icfModule_v2_34` не трогать никогда.
3. Ещё раз `node tests/selftest.mjs` (после смены номера отпечаток другой).
4. Git: `git add -A . && git commit -m "ICF SINGAPORE NN: что изменилось"`, `git tag icf-NN`, `git pull --rebase`, `git push && git push origin icf-NN`.
5. Копия для работы: `cp app/icf-singapore.html "dist/ICF SINGAPORE NN.html"` (папка `dist/` в git не идёт). Положи её на Google Диск в папку проекта — если в этой сессии подключён Диск (коннектор), сделай это сама; если нет — скажи владелице одной строкой, что копия лежит в `dist/` и на Диск не ушла.
6. База (`/zapis`): страница проекта — раздел версии «было → стало» с перечнем правок и проверок, Журнал, log.md, `finish.py` → «ГОТОВО».
7. Владелице: номер версии, что вошло, чем проверено, где файл.
