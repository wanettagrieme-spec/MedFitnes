# ICF SINGAPORE — переехал

Протокол ICF SINGAPORE и его настройка для Claude Code живут в отдельном приватном репозитории:
**https://github.com/wanettagrieme-spec/icf-singapore** (с 29.10.2026, история перенесена).

Причина: облачный Claude Code (claude.ai/code, в том числе с iPad) применяет хуки и правила проекта, только когда проект — корень репозитория.
