# ICF SINGAPORE — рабочая папка для Claude Code

Протокол осмотра МДРК на основе МКФ (`app/icf-singapore.html`) и всё, что нужно Claude Code, чтобы работать с ним по вашим правилам.

## Что здесь
| Папка / файл | Зачем |
|---|---|
| `app/icf-singapore.html` | Сама программа. Имя постоянное, номер версии внутри (`APP_VERSION`). |
| `CLAUDE.md` | Правила для Claude: ваш порядок работы, запреты, где знания. |
| `.claude/hooks/` | Автоматика: старт по Карпаты, защита файла, проверка после каждой правки, запрет закончить без проверки и записи в базу. |
| `.claude/skills/` | Команды `/pravka`, `/proverka`, `/pechat`, `/sverka`, `/vypusk`, `/zapis`. |
| `.claude/agents/` | Независимый ревьюер — проверяет правку «со стороны». |
| `tests/` | Самотест в настоящем браузере и PDF-прогон печати. |
| `docs/КАРТА-КОДА.md` | Где что в файле. |

## Как начать (один раз)
1. Открыть Claude → режим **Code** → выбрать эту папку (на Mac или в облаке через GitHub).
2. Первой просьбой написать: «подготовь проект» — Claude сам выполнит `tests/setup.sh` (ставит браузер для самотеста) и при необходимости склонирует базу medfit-vault рядом с проектом.

## Как работать
- «/pravka добавь в печать протокола …» — Claude изучит, расскажет, что понял, и **будет ждать вашего «делай»**.
- «/proverka» — самотест: 40+ проверок кликами, путь каждого из 12 каталогов до назначения и печати.
- «/pechat» — PDF печатных форм, чужой принтер, ч/б.
- «/vypusk» — новая версия ICF SINGAPORE NN: GitHub, Диск, база.
- В конце любой работы Claude сам вносит запись в базу; закончить без «ГОТОВО» от `finish.py` ему не даст хук.
