## Состояние карты
- `protocol` — карта пациента (39 полей присваиваются в коде; многие создаются по ходу работы, в пустой карте их нет).
- `functional.adm/dis` — шкалы поступления и выписки; `rows` — строки МКФ (`admR/admK/disR/disK`, `sources/manual/autoValues`).
- `protocol.ipmr` — назначения: `btlPick` (методы), `btlHilt/btlSis/btlTecar/btlEswt` (у УВТ выбор по `key`, не по `id`), `btlMagnet/btlMicrowave/btlLllt/btlSono`, `btlElectro`, `wlPick`, `btlMassage`, `btlLfkSop`.
- Переносятся между картами только настройки рабочего места: `carryOverSettings()` — dept, scaleRole, kinesioAbsent, factorOpen, icfBookTab, icfBookQ, printFullFactorForm.

## Хранилища браузера (localStorage)
- `icfModule_v2_34` — текущая карта (STORE). **Не менять никогда.** Старые ключи `icfModule_v1…v2_33` — для чтения прежних карт.
- `icfModule_patients_v1` — архив карт; `icfModule_outcomes_v1` — журнал исходов (отдельно от архива); `icfModule_mdrkRoster_v1`, `icfModule_lastDept_v1`, `icfModule_theme`.
